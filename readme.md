# TeamOS

Multi-tenant SaaS project management platform inspired by Linear and Asana.

## Tech Stack

Frontend:
- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

Backend:
- Node.js
- Express
- TypeScript
- PostgreSQL
- Prisma

Infrastructure:
- Redis
- BullMQ
- Docker
